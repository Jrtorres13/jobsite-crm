JOBSITE CRM - construction CRM with a job pipeline
===================================================

INSTALL (Windows 10/11, about 1 minute)
1. Unzip this folder anywhere.
2. Double-click Install.bat
   (If Windows says "protected your PC": More info > Run anyway.)
3. Done. It opens now. Desktop + Start Menu shortcuts are added.

Mac / other: just open app/index.html in Chrome or Edge.

FIRST STEPS
1. Look around - it starts with demo jobs.
2. Dashboard > "Clear demo data" when ready.
3. Settings: company name, phone, license #, tax %, markup %,
   crews, lead sources, job types.

DAILY USE
- New lead (top right): customer + job + follow-up task in one step.
- Job Pipeline: drag jobs through 11 stages, New Lead to Paid.
  Moving a job auto-adds the next follow-up task.
  Orange day count = stuck 7+ days.
- Click any job for: estimate builder, change orders, invoices +
  payments, job costing (budget vs actual), tasks, notes, photos.
- Print / PDF: estimates, invoices and change orders.
- Schedule: month calendar of jobs by crew + task due dates.
- Tasks: overdue / today / upcoming.
- Invoices & Payments: what's owed, overdue aging, recent payments.
- Export CSV: jobs, customers, invoices.

PRIVACY + BACKUP
- Everything is saved only on this PC (%LOCALAPPDATA%\JobSiteCRM).
- Settings > Download backup. Do this weekly.
- Restore it on any PC with Settings > Restore from backup.

UPDATE: unzip the new version, run Install.bat again. Data stays.
REMOVE: run Uninstall.bat.
